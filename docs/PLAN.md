# Earbuds → ідеал: план

Один власник, один телефон (**Pixel 10 Pro XL**, Android 16) і одні навушники (**Sony WF-1000XM5**).
Кожне рішення нижче випливає з цього.

Позначки: ✅ зроблено · 🔜 наступне · 🧪 спершу треба захопити протокол · ❌ свідомо не робимо.

## 1. Що вже є (1.1 → 1.2)

**1.1 (гілка `restore-and-core-refactor`):**
- одне ядро стану (`DeviceState`) і один механізм відповідей;
- сторінки в стилі Pixel з predictive back;
- сцени (згодом прибрані на прохання власника), оцінка часу прослуховування, миттєвий показ останньої батареї, підказка про LDAC.

**1.2 (ця гілка):**
- ✅ **Кільця батареї як у Pixel Device details.**
  - Продукт лежить на заповненому диску, навколо тонке кільце з відступом.
  - Чип стоїть на кільці, а кільце обривається рівно біля його обведення.
  - Окремий квадратний вирізаний навушник, по центру. Раніше з широкого фото обох навушників вирізався шматок 54 dp, звідси «кривуватість».
  - Арт займає ≤ 1/√2 диска, тому ніколи не обрізається краєм.
  - Підпис «Left: 69%», як у Pixel.
- ✅ **Реакція на підключення навушників без сервісу** (ACL-broadcast).
  - Коли дістаєш з кейсу: читається батарея, оновлюються віджети, за бажанням вмикається режим.
  - Налаштування «When earbuds connect»: *Don't change* / ANC / Ambient / Off.
  - Коли ховаєш у кейс: запам'ятовується час, віджети приглушуються, на головній «Disconnected · 25 minutes ago».
- ✅ **Двоетапні haptics.**
  - Тік одразу під пальцем.
  - Коли навушники підтвердили: свій імпульс для кожного режиму (ANC — глухий thud, Ambient — quick rise, Off — tick).
  - Якщо не вдалося: подвійний клік.
  - Застарілі тапи з серії мовчать.
- ✅ **Find замість Disconnect.** «Disconnect» закривав лише канал керування, не звук: заплутував і сповільнював наступний тап.
- ✅ **Віджети** — див. розділ 2.
- ✅ **CI:**
  - постійний ключ підпису з секретів;
  - `versionCode` = номер запуску CI;
  - захист від повторення `5cac169`, коли коміт стер усе дерево.

## 2. Віджети: як влаштовано

**Принцип:** жодних «брейкпоінтів навмання». Launcher повідомляє точні розміри віджета (портрет/ландшафт, `OPTION_APPWIDGET_SIZES`). Для кожного розміру будується свій layout за правилами з `WidgetLayout`. Це чиста функція з unit-тестами на реальних розмірах комірок Pixel 10 Pro XL.

### Режими (ANC / Ambient / Off)

| Розмір (приклад) | Вигляд |
|---|---|
| 5×1, 4×1 широкий | Ряд, іконка **поруч** з підписом |
| 3×1 | Ряд, іконка **над** підписом |
| 2×1 | Ряд, лише іконки (підпис не влазить — не обрізаємо, а ховаємо) |
| 4×1 низький | Ряд, іконка поруч з підписом, 1 рядок |
| 2×2, 2×3 | Колонка з трьох пігулок |
| 4×2 | Ряд по центру, кнопки не роздуваються в «стіну» |

Деталі:
- **M3E connected button group:** зовнішні кути повністю круглі, внутрішні 8 dp, вибрана кнопка — повна пігулка. У колонці зовнішні кути 28 dp, бо повне заокруглення робило «купол».
- Висота ряду обмежена: 80 dp з підписами під іконками, 64 dp без них. Інакше пігулки перетворюються на кола і «D».
- Шрифт — системний Google Sans Pixel. Ширина підпису **вимірюється** з урахуванням масштабу шрифту, тож «Ambient» не обрізається і на 130 %.
- Кути фону — системний радіус віджетів Android 12+.
- Навушники в кейсі (ACL disconnected) → кнопки приглушені на 38 %, але працюють. Тост пояснює, що навушники не підключені.
- Прев'ю в пікері генерується з того самого коду (Android 15+ `setWidgetPreview`).

### Дашборд (екран блокування та 4×2 і більше)

Той самий віджет режимів. Коли місця вистачає (слот хабу на екрані блокування Pixel 10 Pro XL ≈ 416×275 dp, домашній 4×2 ≈ 340×208), він сам перебудовується. Згори вниз:

1. Назва навушників і статус: «Updated 14:32» / «Disconnected 13:10». Тап відкриває застосунок.
2. Три кільця L / Case / R з відсотками, блискавкою під час заряджання й червоним ≤ 20 %.
3. Час: «**5 h 30 min** left · case **+12 h 20 min**» — числа виділені.
4. ANC / Ambient / Off: connected group 56 dp, іконка поруч з підписом. Якщо підпис не влазить — тільки іконки.

Рядок 3 з'являється лише коли влазить. Категорія віджета — `home_screen|keyguard`. Прев'ю для хабу генерується окремо.

### Батарея (необов'язковий)

| Розмір | Вигляд |
|---|---|
| 1×1 | Одне кільце — навушник, що розрядиться першим; «Case 56%» під ним |
| 2×1, 3×1 | Три кільця L / Case / R з підписами |
| 3×2, 4×2 | Більші кільця + «Updated 14:32» або «Disconnected 13:10» |
| Низький | Без підписів, кільця менші |

Деталі:
- Кільця з тими ж кольорами, що в застосунку: зелене, червоне ≤ 20 %, сіре — невідомо. Блискавка під час заряджання.
- Час абсолютний: віджет не опитує, тож «5 хв тому» збрехало б уже за годину.
- Оновлюється, коли застосунок або подія підключення прочитали батарею.

## 5. Перевірка на телефоні (≈ 10 хв)

1. Встанови нову збірку. Якщо налаштовано ключ (README → *Stable updates*), то один раз видали стару версію, далі оновлення ставитимуться поверх.
2. **Кільця:** навушник і кейс по центру дисків, нічого не обрізано, чип «вирізаний» з кільця.
3. **App settings → When earbuds connect = ANC.** Закрий застосунок, сховай навушники в кейс і дістань: за ~3–5 с має ввімкнутись ANC. Віджет батареї покаже свіжий час.
4. **Сховай у кейс:** кнопки віджета режимів тьмяніють, на головній «Disconnected · …».
5. **Тапни ANC/Ambient/Off:** спочатку тік, потім відчутний імпульс підтвердження. Навушники в кейсі → подвійний клік.
6. **Find** відкриває Find Hub.
7. **Розміри віджетів:** розтягни віджет режимів 2×1 → 5×1 → 2×2 → 4×2; підписи ніде не обрізані, пігулки не стають колами.
8. **Екран блокування:** видали старий віджет з хабу й додай заново (щоб launcher передав новий розмір). Має з'явитися дашборд.
