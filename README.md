# Sony ANC — тестовий застосунок

Один екран: вибір спарених навушників → Підключити → три режими (Шумозаглушення / Прозорість / Вимк).
Знизу лог усіх кадрів, що йдуть до навушників і від них, плюс поле для сирих hex-команд.

## Збірка

**GitHub Actions (без Android Studio):** залий папку в репозиторій → вкладка Actions → `Build APK` → завантаж артефакт `SonyAnc-debug`.

**Локально:** відкрий папку в Android Studio (він сам підтягне Gradle) → Run.
Або з CLI, якщо стоїть Gradle 8.11+ і Android SDK: `gradle :app:assembleDebug`.

## Як перевіряти

1. Навушники мають бути вже спарені з телефоном (системні налаштування Bluetooth).
2. Офіційний Sound Connect краще закрити: він може тримати той самий RFCOMM-канал.
3. Підключити → у лозі має з'явитися `← ACK` і відповідь з типом `0C` на init `00 00`.
4. Тиснути режими. Якщо навушники відповіли ACK, але режим не змінився — у тебе модель з протоколом V2 (покоління XM5): експериментуй через поле hex.

Payload'и в `SonyProtocol.kt` розраховані на XM3/XM4-покоління.
